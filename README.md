魏文帝与野兽论

黄初中，帝燕坐西阁。阴雨连夕，北风入牖，庭树萧然。帝方论文章气骨，顾谓左右曰：“文以气为主。气之清浊有体，不可力强而致。”

俄有橘獸衔生鼷入，目炯然。衔生鼷置几下，踞而视之。鼷欲走，獸按之，不甚力而鼷不能动。左右将逐之，帝曰：“勿逐，是獸亦有气。”

帝曰：“凡物之名，多过其实。此独名野兽，而实亦野兽，名实相副。”野兽忽言曰：“名者，人所饰；实者，爪所定。鼠入我爪，鼠即鼠。”

帝曰：“獸何知文？”野兽曰：“世之文士，多知文而不知鼠。”獸复按鼷。鼷须动足蹶，未死。帝曰：“子不杀之，何也？”野兽曰：“杀则事绝，不杀则势存。权者，使其不得走，未必使其即死。”帝曰：“此人君之权也。”

外有犬吠，獸举首，耳微动，复不出。帝曰：“声大者不足应。”野兽曰：“犬声在门，鼠齿在仓；门可闭，仓难守。”

屏后微有声，帝顾之，见玳瑁小猫于暗处伏而窥鼷。左右曰：“此小点点也。见人则匿，见鼠则奋，不可久抱。”野兽曰：“小点点不争名，不近人。然鼠动，则心动。此得其隅者也。”帝曰：“何谓得其隅？”野兽曰：“大庭之中，犬可吠，人可言，鼠可走。隅中则静。小点点处隅，故能观；有所畏，故能全；有所欲，故能发。”帝曰：“此亦有性。”

帝曰：“文士饰名，辩士饰诈，儒生饰仁，法吏饰刑。饰久则实亡。獸不饰，见鼷则捕，见犬则拒，见人则观。”野兽曰：“饰爪则钝，饰牙则迟。鼠不畏文采。”獸忽纵鼷。鼷走数步。小点点自屏后暴起，未及至，野兽复跃而衔之。小点点即却，复伏于隅。野兽曰：“有文无爪，鼠食其书；有爪无文，人畏其暴。”

左右默然。帝叹曰：“文章经国，然经国不独在文。文所以存名，爪所以制实。无文则暴，无爪则乱。”

野兽衔鼷将出，行数步，复返，取案上脯一片，置屏下小点点前。小点点食之。帝曰：“此何意？”野兽曰：“能伏者，当有食。能观者，亦有功。”帝曰：“善。功不必皆在前，伏隅者亦佐其势。”

帝曰：“此獸不可官。官之，则失其野。”野兽曰：“官我，则我先食官鼠。”遂出。

帝乃书曰：“橘獸衔鼷，名实相得；小点点伏隅，动静相资。犬吠于外，声不胜气；鼠伏于爪，形不胜势。文可以饰名，爪可以制实。故观野兽，可以知政；观小点点，可以知性。”
